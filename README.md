# LiNEA40 keymap の判定ルール

40% + 1u トラックボール + 日本語入力向けの、クリック／句読点／スクロールの切り替えメモ。アルファベットの物理位置は動かさない。

## レイヤー

| 番号 | 名前 | 入り方 |
|---|---|---|
| 0 | デフォルト | — |
| 1 | MOUSE | ボールを動かすと自動。クリック以外のキー、または最後の移動から 1.5s で解除 |
| 2 | MARK（記号） | 右 TAB ホールド |
| 3 | FUNCTION（移動・IME） | 左 Space ホールド |
| 4 | SCROLL（ホイール） | J または M ホールド |

```
Q  W  E  R  T                      Y  U  I  O  P
A  S  D  F  G                      H  J* K  L  -
Z  X  C  V  B                      N  M* MB1† MB2† /
GUI ALT SFT TAB CTL  SPC[FN]  ENT[SFT] TAB[MARK]  ,  .  ;
```

`*` tap は文字、hold は SCROLL。`†` 文脈でクリックか句読点。

修飾は左下の専用キー。右 Enter ホールドが Right Shift。

## クリックと句読点（いちばん複雑）

`ak_mb1` / `ak_mb2` はデフォルトが MB1 / MB2。読点は文の続きでしか打たない、という前提で、**何もしていないときはクリック**にする。

### 優先順位（上ほど強い）

1. **左 Shift 押しながら** → クリック（Shift+ドラッグ用。右手ボールと両立）
2. **右 Shift 押しながら** → `,` / `.`（Shift が乗って `<>`。右 Shift＋ボールは現実的でない）
3. **ボール操作中〜その後（layer 1）** → クリック  
   ボールを動かすと layer 1 が乗る。クリックキー以外を押すか、ボールを止めて 1.5s で外れる。直前の句読点クールタイムは打ち切る。
4. **直前 1.5 秒が文章操作（layer 1 でない）** → 句読点（`,` / `.`）
5. **それ以外（アイドル、Ctrl+S など）** → クリック

### 「文章操作」とみなすもの

- 修飾なしの A–Z、および左右 Shift 付きの A–Z（`OK` など）
- 数字、Space、Enter、BS、一部記号
- LANG1 / LANG2（英数・かな）
- 矢印、Page Up/Down、Home、End
- MARK（layer 2）または FUNCTION（layer 3）に **入ったこと**（内部だけ F21 を出し、ホストには送らない）
- Ctrl/Cmd + C / V / X（コピー・ペースト・カット）

Ctrl / GUI / Alt 付きのその他の文字（Ctrl+S など）は文章操作に入れない。

### 時間

| | 長さ | 意味 |
|---|---|---|
| 句読点クールタイム | 1.5s | 最後の文章キーから。ボール操作で打ち切り |
| MOUSE レイヤー | 1.5s | 最後のボール移動から。クリック（位置 27/28）以外のキーでも解除 |

SCROLL（J/M hold）ではダミーキーを出さない。スクロール中はクリックしたいため。

## J / M ホールド（SCROLL）

1u ボールは親指ホールドと同時操作しにくいので、ボール隣の J / M で SCROLL に入る。

- 次が **文字** → tap（`j` / `m`）。`like` のようなロールで文字が消えないようにする
- 次が **記号・親指**、または 200ms 以上の単独ホールド → SCROLL（ボールがホイール）
- 打鍵直後 125ms 以内の J/M は即 tap
- 同じキーの連打（175ms 以内）は tap のまま（`mm` など）

SCROLL 上の文字キーは使わない。MB3/4/5 は記号と親指。`ak_mb1` / `ak_mb2` 位置は `&trans` なので、通常クリックは下のレイヤーに抜ける。

## 実装上の制約

- adaptive-key の `trigger-keys` は **1 条件あたり 32 個まで**。左右 Shift 付き文字は `after_ls` / `after_rs` に分割している。足すときはこの上限を超えないこと。
- レイヤー入場のマーカは F21（`AK_LAYER_MARK`）。`dead-keys` でホストには出さない。F15 は macOS で使われうるので使わない。
- keymap を並べ替えると J/M の `hold-trigger-key-positions`（キー位置番号）がずれる。
- Shift を押したまま句読点キーを叩くと `,` が `<` になる。大文字のあと Shift は離してから。
